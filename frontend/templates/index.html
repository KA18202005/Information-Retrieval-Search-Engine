Classical IR Query Syntax Reference

1. Boolean Retrieval (Module 5)

Operators: AND, OR, NOT, XOR, and parentheses ( ).

machine AND learning
(systems OR databases) AND NOT deep

2. Exact Multi-Term Phrase Queries (Positional Index)

Enclose terms in double quotes for exact word-order adjacency.

"information retrieval system"
"tokenization and text"

3. Wildcard Queries (Permuterm Index - Module 6)

Supports leading, trailing, and middle wildcards.

mach* (trailing)
*tion (leading)
in*ation (middle)

4. Parametric Field Search

Query specific document attributes (title:, author:, category:, body:).

title:database
author:salton
category:nlp

5. Ranked Retrieval (Vector Space Model)

Free-text queries scored via Sublinear TF ($1 + \ln(tf)$), Smoothed IDF, and Cosine Similarity.

vector space model cosine similarity
